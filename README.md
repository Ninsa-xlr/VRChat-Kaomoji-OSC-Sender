# VRChat Kaomoji OSC Sender 🌸

A Python desktop app built with `tkinter` and `python-osc` for sending a collection of kaomojis directly to your VRChat chatbox over OSC (`/chatbox/input`).

![Python Version](https://img.shields.io/badge/python-3.6%2B-blue.svg)
![OSC Enabled](https://img.shields.io/badge/VRChat-OSC-purple.svg)
![Theme](https://img.shields.io/badge/theme-Dark%20Purple-ff77ff.svg)

---

## ✨ Features

* **🎨 Custom menu colors:** Use the hue slider in Settings to recolor the entire interface.
* **📂 Kaomoji categories:** Browse kaomojis by category using the dropdown menu.
* **🔍 Live search:** Search the full collection by category name or kaomoji.
* **⚡ One-click sending:** Click a kaomoji to send it directly to your VRChat chatbox.
* **🪟 Console-free launch:** Open the `.pyw` app file on Windows to launch without a separate terminal window.
* **🛡️ Startup error handling:** Displays an error message if the application cannot start.

---

## 📋 Prerequisites

Make sure you have **Python 3** installed on your system. You will also need the `python-osc` library to handle network communication with VRChat.

Open your terminal or command prompt and run:
```bash
pip install python-osc
```

On Windows, double-click `VRChat Kaomoji OSC Sender.pyw` to launch the app without opening a terminal window.
